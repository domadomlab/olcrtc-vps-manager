# 📖 Полная Wiki: olcRTC VPS Manager

Добро пожаловать в базу знаний проекта. Здесь описаны все нюансы работы системы.

## 🧭 Архитектура системы
Система состоит из трех основных компонентов, работающих в связке:
1.  **olcRTC Server (Docker):** Основной движок туннеля, который маскирует трафик под видеозвонок.
2.  **Telegram Bot (Python):** Интерфейс управления. Позволяет не заходить на SSH для повседневных задач.
3.  **Watchdog (Cron):** Скрипт-страж, который следит за стабильностью 24/7.

## 📡 Параметры соединения
По умолчанию используются настройки, обеспечивающие максимальную стабильность:
*   **Carrier:** `telemost` (Яндекс.Телемост)
*   **Transport:** `vp8channel` (наиболее устойчивый к потерям пакетов)
*   **FPS:** `30`
*   **Batch:** `2` (баланс между задержкой и пропускной способностью)

## 🔑 Управление доступом (Multi-User)
В версии v1.4.0 добавлена поддержка нескольких пользователей. 
*   Каждый QR-код, сгенерированный через кнопку **"➕ Новый пользователь"**, создает уникальную сессию.
*   Это позволяет нескольким людям использовать один VPS без взаимного "выбивания" из сети.

## 🚑 Решение проблем

### Бот не отвечает
1. Проверьте статус контейнера: `docker ps`.
2. Посмотрите логи: `docker logs olcrtc-bot`.
3. Убедитесь, что в `.env` прописан правильный `TELEGRAM_BOT_TOKEN`.

### Интернет пропал, но статус "Active"
Скорее всего, комната в Телемосте была закрыта Яндексом.
*   **Решение:** Создайте новую встречу в Телемосте, скопируйте её ID и отправьте боту через команду **"🚪 Сменить комнату"**.

### Ошибка "Conflict: container name already in use"
Это происходит при попытке переустановки поверх старой версии.
*   **Решение:** Скрипт `deploy.sh` теперь автоматически чистит старые контейнеры, но если проблема осталась, используйте `docker rm -f olcrtc-server olcrtc-bot`.

## 🔄 Обновление
Чтобы обновить систему до последней версии с сохранением настроек:
```bash
cd /root/olcrtc-manager
git pull
docker compose up -d --build
```
Или просто запустите One-Liner установщик повторно.
