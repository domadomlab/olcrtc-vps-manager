# Инструкция по использованию olcRTC туннеля

Данная инструкция поможет вам подключиться к вашему VPS серверу через маскировочный туннель Яндекс.Телемост.

## 1. Где взять клиентское приложение

Для работы туннеля необходимо приложение **olcRTC Client**.

*   **Android:**
    *   Актуальные сборки (.apk) берутся в официальном репозитории разработчика: 
        [https://github.com/openlibrecommunity/olcrtc/releases](https://github.com/openlibrecommunity/olcrtc/releases)
    *   *Примечание:* Ищите файл с названием `olcrtc-android-client.apk`.

*   **Windows / Linux / macOS:**
    *   Бинарные файлы для ПК также доступны в разделе Releases:
        [https://github.com/openlibrecommunity/olcrtc/releases](https://github.com/openlibrecommunity/olcrtc/releases)

---

## 2. Как подключиться (Инструкция для Android)

1.  **Установите APK** на ваш телефон.
2.  **Скопируйте URI подключения** (сгенерированный при установке).
3.  **Откройте приложение** olcRTC.
4.  Нажмите кнопку **"+"** (Добавить конфигурацию) или **"Import from Clipboard"** (Импорт из буфера).
5.  Проверьте, что в настройках (Settings) приложения включен режим **SOCKS5 Proxy**.
6.  Нажмите на созданный профиль и выберите **"Connect"**.
7.  Когда статус изменится на **"Connected"**, ваш интернет-трафик пойдет через VPS.

---

## 3. Данные для подключения (URI)

Используйте URI, который выдает инсталлятор или Telegram-бот. Формат ссылки выглядит так:

```text
olcrtc://telemost?vp8channel<vp8-fps=30&vp8-batch=2>@ROOM_ID#KEY%client-id$NAME
```

---

## 4. Параметры сервера (для справки)

*   **IP сервера:** Ваш внешний IP VPS
*   **Метод маскировки:** Яндекс.Телемост (видеопоток VP8)
*   **DNS:** 1.1.1.1 (Cloudflare)
*   **Режим работы:** Direct Link (P2P через облако Яндекса)

---

## 5. Решение проблем

*   **Нет интернета:** Проверьте, что в браузере или системе включен SOCKS5 прокси (обычно `127.0.0.1:1080`).
*   **Частые обрывы:** Попробуйте уменьшить качество видео на YouTube или проверить стабильность мобильной связи.
*   **Ошибка "Conference Not Found":** Необходимо обновить Room ID в конфигурации через Telegram-бота.
