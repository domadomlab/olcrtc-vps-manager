## 🚀 Быстрый старт (Установка за 2 минуты)

Запустите эту команду на своем VPS (Ubuntu/Debian):

```bash
curl -sSL https://raw.githubusercontent.com/domadomlab/olcrtc-vps-manager/main/scripts/deploy.sh | bash
```

**После запуска вы получите:**
1.  **Рабочий туннель olcRTC**, замаскированный под WebRTC.
2.  **Telegram-бота** для дистанционного управления без SSH.
3.  **Авто-мониторинг**, защищающий от зависаний и блокировок.

## 💎 Почему olcRTC Manager?

В отличие от стандартных VPN (VLESS, Shadowsocks, WireGuard), этот проект использует **биологическую маскировку** трафика. Для провайдера ваше соединение — это обычный разговор двух людей в видеочате. 

**Основные преимущества:**
*   **Непробиваемость:** WebRTC-трафик практически невозможно отличить от легального.
*   **Автономность:** Система сама чинит себя при сбоях.
*   **Простота:** Весь сложный бэкэнд скрыт за кнопками мессенджера.
