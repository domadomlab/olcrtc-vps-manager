# 🛸 olcRTC VPS Manager (v1.4.0 LTS)

Комплексная система для автоматического развертывания и управления туннелем **olcRTC** на VPS. Превращает ваш сервер в мощный хаб для обхода блокировок через Яндекс.Телемост с управлением через Telegram.

## 🚀 Быстрый старт (One-Liner)

Запустите эту команду на чистом VPS (Ubuntu/Debian) для полной установки "под ключ":

```bash
curl -sSL https://raw.githubusercontent.com/domadomlab/olcrtc-vps-manager/main/scripts/deploy.sh | bash
```

**Что произойдет:**
1. Установятся Docker и все зависимости.
2. Скрипт предложит ввести **Room ID** и **Telegram Bot Token**.
3. Развернется туннель и управляющий Telegram-бот.
4. В конце вы увидите **два QR-кода**: для подключения интернета и для запуска бота.

---

## 🤖 Управление через Telegram

Ваш бот — это полноценный пульт управления сервером.

### Основные функции:
*   **📊 Статус** — живая статистика трафика и текущая комната.
*   **📱 Мой QR** — мгновенное получение кода для подключения.
*   **🚪 Сменить комнату** — дистанционное обновление ID Телемоста без SSH.
*   **➕ Новый пользователь** — создание уникальных QR-кодов для друзей или других устройств.
*   **🔄 Рестарт** — перезагрузка туннеля одной кнопкой.

> **Безопасность:** Бот автоматически привязывается к первому, кто нажмет `/start`, и игнорирует всех остальных.

---

## 🛠 Ручное управление (SSH)

Если вам нужно зайти на сервер вручную:
*   **Директория проекта:** `/root/olcrtc-manager`
*   **Интерактивное меню:** `./manage.sh`
*   **Логи туннеля:** `docker logs -f olcrtc-server`
*   **Логи бота:** `docker logs -f olcrtc-bot`

---

## 🛡 Отказоустойчивость
В систему встроен **Smart Watchdog v2.0**, который каждую минуту проверяет:
1. Не упал ли процесс туннеля.
2. Не зависла ли сессия (Smux stall).
3. Доступна ли конференция в Яндексе.
При обнаружении проблем вочдог автоматически "лечит" соединение за несколько секунд.
